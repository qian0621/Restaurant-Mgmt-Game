# Evidence from earlier stages

Transcripts and test notes of earlier stages are kept here so the stage-to-stage comparison can be
checked. They are only valid against the code of their own tag (the rules and arrival schedules
changed on purpose in later stages). To reproduce one, check out the tag and use `tests/stageN/`:

    git checkout stage-1 && tests/run_tests.sh 1
    git checkout stage-2 && tests/run_tests.sh 2
